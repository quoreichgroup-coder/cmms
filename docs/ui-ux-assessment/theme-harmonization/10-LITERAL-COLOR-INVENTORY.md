# Inventaire des couleurs littérales — Mobile

Cet inventaire extrait les couleurs écrites directement dans le code mobile, avec le chemin relatif, la ligne source et le texte de la ligne pour retrouver leur usage. La relecture du 12 octobre 2026 a supprimé une entrée périmée (`NotFoundScreen` emploie déjà le token primaire) et quatre couleurs explicites des squelettes `WelcomeScreen`/`TabTwoScreen`, désormais reliés au thème : le relevé comprend **99 occurrences dans 18 fichiers**. Les six couleurs d’exemple retirées de `EditScreenInfo.tsx` ont été remplacées par des couleurs Paper/QPM; le relevé reste un index lexical à qualifier et non une liste de défauts.

Le détail est fourni en [CSV](10-LITERAL-COLOR-INVENTORY.csv), filtrable dans un tableur. La recherche couvre les fichiers `.ts`, `.tsx`, `.js`, `.jsx`, `.css`, `.scss` et `.json` sous `mobile/`; les répertoires générés ou de dépendances `node_modules`, `.build-tools`, `android`, `ios`, `build`, `dist`, `.expo` et `.expo-export-check-*` sont exclus. Elle repère les valeurs hexadécimales, les fonctions `rgb()`/`rgba()` et les noms de couleur CSS usuels sur les lignes comprenant des propriétés de couleur, y compris les clés sémantiques de la palette. Le relevé reste lexical et peut ne pas inclure les valeurs construites par expression.

Il s’agit d’un relevé lexical, pas d’une classification sémantique complète. Une ligne peut contenir plusieurs couleurs ou un faux positif dans une chaîne/commentaire; les couleurs calculées, constantes importées, valeurs natives hors extensions listées et tokens référencés ne sont pas des littéraux et ne sont donc pas comptés. Vérifier chaque occurrence dans son contexte avant de la remplacer. Les couleurs d’état métier doivent être rapprochées des tokens sémantiques, sans modifier leur signification.

Cet inventaire est lexical; la classification par contexte est consignée dans [11-COMPONENT-COLOR-REVIEW.md](11-COMPONENT-COLOR-REVIEW.md). Utiliser les colonnes `file` et `line` pour retrouver les usages et décider lesquels relèvent de la marque, d’un statut, d’une illustration ou d’une exception fonctionnelle.
