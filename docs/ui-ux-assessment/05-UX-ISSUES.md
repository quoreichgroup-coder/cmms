## Confirmed issue count

Using the confidence and severity above: **1 confirmed critical operational issue from supplied logs** and **1 medium visual issue confirmed in a dated historical screenshot**; no current-build visual defect has been reproduced in this assessment. Two documented runtime defects await current-instance revalidation (analytics opaque error and previous PM field feedback); remaining listed items are usability hypotheses or architecture facts with unmeasured impact. Do not add hypotheses to confirmed defect totals.

## Top 10 improvement opportunities

1. Stabilize API start/schema compatibility and make failure recovery visible (UXR-01).
2. Revalidate and standardize analytics loading/error/empty/retry behavior (UXR-02).
3. Reorganize navigation around role tasks while protecting existing permission/feature filters (UXR-03).
4. Optimize technician mobile Home → assigned WO → execution → completion (UXR-04, UXR-06).
5. Progressive disclosure for PM standard vs strategy/multi-counter setup (UXR-05).
6. Turn equipment detail into a clear 360 entry point across history/WO/meters/files/parts (routes in app.tsx, `Assets/Show`).
7. Adopt consistent data-table recipes and intentional mobile list/card behavior (UXR-07).
8. Standardize field-level validation, disabled/saving/success feedback and server error recovery (UXR-09).
9. Test responsive/accessibility coverage for priority screens before broad restyling (UXR-08).
10. Clarify company/site/licensing/document snapshot states and audit actions (UXR-10, UXR-11).
