Interactions et limites

Les onglets, filtres, navigation, tâches, formulaires et états sont simulés côté navigateur. Aucun appel API ni enregistrement réel. Les écrans conservent les concepts de rôle et les flux présents, sans vérifier les permissions. Le dossier ne modifie pas les sources de production.
